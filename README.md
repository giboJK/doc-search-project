# doc-search-project


## Commit message rule

| Type     | Description    |
| -------- | -------------- |
| feat     | 새운 기능 추가       |
| fix      | 버그 수정          |
| docs     | 문서 수정          |
| style    | 코드 스타일 수정      |
| refactor | 코드 구조 개선       |
| test     | 테스트 코드         |
| chore    | 기타 작업(환결 설정 등) |
